run · open-source/agentsauthor · public repos

Agents and evals, in the open

Two public repos: a LangGraph medical scribe built as a runnable tutorial, and a PM agent that mines apache/superset and audits its own report.

scribe-health-ai-agentApache-Superset-PM-AgentWrite-up on Medium

LangGraph scribe
A triage node routes each transcript to a pediatrics or general medicine agent, which writes a SOAP note with tools. A confidence gate sends doubtful input to human review instead of guessing. Both graphs are registered for LangGraph Studio and every run is traced in LangSmith.
Superset PM agent
Pulls releases, issues and discussions from apache/superset, scores them with a transparent heuristic, and has Claude write a prioritized PM report. Each run emits an OpenInference span tree.
Evaluation
The scribe repo benchmarks LLM-as-a-judge triage against a decision model on six transcripts, five runs each. Routing accuracy tied at 87%, but the LLM reported 0.90 confidence on a case it got wrong, so its confidence could not drive the gate. The PM agent has a citation-faithfulness eval that exits non-zero on any fabricated issue reference, and a scoring eval that checks the heuristic against an LLM judge by rank correlation.

run · heliodx/findingssolo founder · product + build

A team of agents reading chest X-rays

HelioDX drafts imaging findings for clinics that have no radiologist. The first use is tuberculosis screening. The clinician reviews every draft and makes the diagnosis.

Source on GitHubLive appEval resultsDemo videoheliodx.com

Problem
Many clinics in Nigeria take chest X-rays that no radiologist ever reads. A draft has to be useful to a general clinician and must never present itself as a diagnosis.
What I built
Meta Muse Wonder coordinates a team of Muse Glimmer agents that take a film from intake to a signed report. Meta SAM 3.1 segments every scan first, so each finding points at the region it rests on. Glimmer and SAM run on a private Cloud Run GPU through vLLM, so images and reports stay inside the project, and every agent step is recorded in an auditable trace. A guard in code, not only in the prompt, rejects any model answer that names a disease. Built solo for the Meta Global AI Developer Hackathon and open source under AGPL-3.0.
Evaluation
160 code-graded tasks on public chest X-rays (NIH ChestX-ray14 and the Shenzhen TB screening set), run head to head against MedGemma 27B on the same GPU with the same masks. HelioDX was about twice as fast at about half the cost per task. Every task and score is published, including the weaknesses: neither system flagged a normal film, and both missed most TB-labelled films. It has not been validated in a clinic, and the product is positioned accordingly. The method is in the eval README.

run · newcare/scribesoftware builder · product + build

An AI scribe I could measure

NewCare is a clinical documentation and prescription-routing platform for Nigerian clinicians. The Scribe turns a recorded consult into a SOAP note.

iOS app on the App Store

Problem
A scribe that invents a finding is worse than no scribe. Early prompt versions fabricated details, mishandled exams the doctor deferred, and missed transcription flags. Consults also switch between English and Yoruba, Igbo, Hausa or Pidgin mid-sentence.
What I built
Note generation on a self-hosted MedGemma 4B served through vLLM on a private Cloud Run service. I am moving it to a retrieval design that matches diagnoses against an ICD-10 index and pulls medications from a drug catalog, with specs written as a shared contract plus backend and mobile documents for coding agents to implement.
Evaluation
An LLM-as-a-judge eval scores every note. I track scores per prompt version in Langfuse and iterate against each failure mode by name. A small group of physicians has used the mobile alpha on real consults since late August 2026 to build benchmarks.
